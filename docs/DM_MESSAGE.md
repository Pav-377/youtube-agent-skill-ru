Держи! Бесплатный YouTube-агент для Claude на русском: сценарии, названия, монтажный лист, удержание и ещё 7 скиллов.

Установка в Claude Code за 3 шага:
1. /plugin marketplace add Pav-377/youtube-agent-skill-ru
2. /plugin install youtube-agent-ru@youtube-agent-skill-ru
3. Перезапусти и напиши: «Напиши сценарий про…»

Для claude.ai и подробности: github.com/Pav-377/youtube-agent-skill-ru
