# Ограничения

## Что плагин не делает

- Не публикует ролики и не отвечает на комментарии. Плагин готовит текст, публикуете вы.
- Не монтирует видеофайлы. `/yt-edit` выдаёт монтажный лист, резать нужно в своём редакторе.
- Не входит в аккаунт YouTube. Скрипты плагина не обращаются к сети. `/yt-viral` может предложить
  собрать открытые списки роликов через yt-dlp, только с вашего разрешения.
- Работает только с YouTube. VK Видео и RuTube не поддерживаются.

## Оценки

- Оценка хука отсеивает слабые начала и подсказывает, что исправить. Просмотры она не предсказывает.
- Оценку проверили на первых 15 секундах 226 роликов из 15 русскоязычных каналов. Ролики, набравшие
  вдвое больше медианы своего канала, получили в среднем 30,1 балла. Ролики с просмотрами ниже
  половины медианы получили 30,3 балла.
- На заранее размеченных хуках оценка ставит нормальный хук выше слабого в 98% пар.
- В русском режиме у оценки хука нет меток «слабый» и «сильный». Сравнивайте варианты между собой по
  баллу.
- В английском режиме метки WEAK, WORKABLE и STRONG стоят на порогах оригинала. Большинство хороших
  хуков получают метку WEAK.
- Формула в отчёте `/yt-viral` описывает слова названия. Почему ролик набрал просмотры, она не
  объясняет.
- Черновые названия глав составлены из слов темы. Перед публикацией их нужно переписать.

## Монтажный лист

- В автосубтитрах YouTube почти нет заминок «э» и «мм»: распознавание их пропускает. Чтобы найти
  заминки, используйте транскрипт Whisper.
- В файле `.srt` время каждого слова примерное и помечено знаком ≈.
- В автосубтитрах время конца последнего слова строки оценивается по длине слова. Паузы на стыках
  строк примерные, прослушайте их перед монтажом.
- Слова «реально», «прям», «на самом деле» и «так сказать» не вырезаются автоматически. Чтобы их
  убирать, впишите их в профиль автора.
- Правила проверены на 260 размеченных словах из пяти роликов. Точность решения «вырезать»
  составила 96,6%.

## Выгрузка из YouTube Studio

- Русские названия столбцов не сверены с реальной выгрузкой. Если скрипт не найдёт столбец
  удержания, напишите Claude, как он называется в вашем файле.
- Хук шортса считается как 10% длины ролика, от 3 до 30 секунд. Правило не сверено с реальными
  выгрузками шортсов.

## Проверка штампов

- Проверка находит приметы машинного текста. Она не определяет, написан ли текст нейросетью.
- Общее «не X, а Y» без слов «это», «дело» и «речь» не отмечается.
- Совет про длинное предложение срабатывает и на живую речь. Он нужен для текста, который будут
  читать вслух.

## Техника

- Нужен Python 3.9 или новее.
- В claude.ai скрипты работают только при включённом выполнении кода.
- В Windows PowerShell 5.1 русские буквы в выводе скрипта могут отображаться неверно, если
  передавать вывод через конвейер вручную. Запуск из Claude это не затрагивает.
