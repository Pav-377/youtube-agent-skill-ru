# Установка

Плагин работает в Claude Code и в claude.ai. В Claude Code устанавливается весь плагин сразу. В
claude.ai каждый скилл загружается отдельным архивом.

## Claude Code

### Через сообщение

1. Откройте Claude Code.
2. Отправьте сообщение: «Установи этот плагин: {{REPO_URL}}»
3. Когда Claude сообщит, что плагин установлен, откройте новый чат.

Claude выполнит в терминале две команды из следующего раздела.

### Командами в терминале

```bash
claude plugin marketplace add {{REPO_URL}}
```

```bash
claude plugin install youtube-agent-ru@youtube-agent-skill-ru
```

Те же действия в чате Claude Code:

```
/plugin marketplace add {{OWNER}}/{{REPO}}
```

```
/plugin install youtube-agent-ru@youtube-agent-skill-ru
```

После установки откройте новый чат или введите `/reload-plugins`.

Если Windows сообщает «Filename too long», выполните один раз и повторите установку:

```bash
git config --global core.longpaths true
```

### Копированием папок

1. Скачайте архив `youtube-agent-skill-ru.zip` со страницы релизов: {{REPO_URL}}/releases
2. Распакуйте его.
3. Скопируйте папки `skills/yt-*` в папку `.claude/skills` в домашней папке. На Windows это
   `C:\Users\ВашеИмя\.claude\skills`.

### Как вызывать команды

Напишите запрос обычными словами, и Claude выберет скилл сам. Команду можно ввести явно:
`/yt-script`. Если это имя занято другим плагином, используйте полную форму:
`/youtube-agent-ru:yt-script`.

## claude.ai

1. Включите выполнение кода. Без него скрипты не запускаются. Где находится настройка, описано в
   [справке Claude](https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude).
2. Скачайте архивы нужных скиллов со страницы релизов: {{REPO_URL}}/releases. Каждый скилл
   лежит в своём архиве: `yt-script.zip`, `yt-edit.zip` и так далее.
3. Откройте Customize → Skills, нажмите «+», затем «Create skill» и «Upload a skill».
4. Выберите архив. Повторите для каждого скилла.

Скиллы доступны на тарифах Free, Pro, Max, Team и Enterprise
([справка Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)).

## Профиль автора

Профиль автора описывает, как вы говорите: на «ты» или на «вы», в каком темпе, какие слова
оставлять. Его используют команды, которые пишут текст.

Напишите Claude «Составь мой профиль автора по трём роликам» и приложите ссылки или транскрипты.

- В Claude Code профиль сохранится в `~/.claude/youtube/voice.md`. На Windows это
  `C:\Users\ВашеИмя\.claude\youtube\voice.md`. Обновления плагина этот файл не меняют.
- В claude.ai вставьте готовый профиль в инструкции проекта.

Чтобы заполнить профиль вручную, скопируйте [шаблон](../templates/voice.ru.md) в
`~/.claude/youtube/voice.md` и редактируйте копию. Шаблон в папке плагина заменяется при каждом
обновлении.

## Если нет Python

Проверьте версию в терминале. На Windows:

```bash
python --version
```

На macOS:

```bash
python3 --version
```

Ответ вида `Python 3.12.4` означает, что Python установлен. Нужна версия 3.9 или новее.

На Windows установите Python командой ниже или установщиком с
[python.org](https://www.python.org/downloads/) с отметкой «Add Python to PATH». Если вместо
версии открывается Microsoft Store, Python не установлен.

```bash
winget install Python.Python.3.12
```

На macOS установите инструменты разработчика или установщик с
[python.org](https://www.python.org/downloads/):

```bash
xcode-select --install
```

После установки Python перезапустите Claude Code.

## Проверка установки

Отправьте Claude три запроса.

1. «Оцени начало ролика: Почему твои видео никто не досматривает?»

   ```
     Почему твои видео никто не досматривает?
     ----------------------------------------
       КОНКРЕТИКА     29  #####
       ОБРАЩЕНИЕ      76  ###############
       СТАВКИ         22  ####
       ЛЮБОПЫТСТВО    93  ##################
       КРАТКОСТЬ      67  #############
       ИТОГ           43
       формула       Вопрос  (совпало шаблонов: 2)
       слабое место  ставки: назовите, что зритель теряет, если продолжит делать как сейчас
   ```

2. «Проверь название: ШОК! Вы не поверите, что сделал Claude»

   ```
     "ШОК! Вы не поверите, что сделал Claude"
     38 символов   оценка 98/100
       x  кликбейт     «шок», «вы не поверите»: многие зрители считают такие слова дешёвым кликбейтом. Это предупреждение, решать вам
       ок              38 символов, помещается в 60 символов на компьютере
       ок              1 слово капсом для акцента
       ок              есть конкретика (Claude)
   ```

3. «Найди штампы: Давайте разберёмся, почему это не просто монтаж, а искусство.»

   ```
     абзац 1, предложение 1  [штамп] противопоставление «не X, а Y»
         «это не просто монтаж, а»
         Скажите прямо, что есть, без того, чего нет.
     абзац 1, предложение 1  [штамп] канцелярская связка
         «Давайте разберёмся»
         Уберите связку или скажите проще, своими словами.

     Штампов: 2, советов для устной речи: 0. Скрипт ничего не переписывает: перепишите эти места своими словами.
   ```

Claude может пересказать отчёт своими словами. Если в ответе есть пять оценок хука, предупреждение
о кликбейте и две находки в третьем запросе, плагин работает.

## Если что-то не так

- **Ответ на английском.** Скрипт не запустился. Проверьте, что Python установлен, а в claude.ai
  включено выполнение кода.
- **«python3 не найден» на Windows.** Скилл повторит запуск через `python`. Если и эта команда не
  найдена, установите Python.
- **Архив не загружается в claude.ai.** Загружайте архивы отдельных скиллов, например
  `yt-script.zip`. Архив `youtube-agent-skill-ru.zip` для claude.ai не подходит.
