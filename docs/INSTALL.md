# Установка

Есть два пути: Claude Code (программа для работы с Claude на компьютере) и claude.ai или Claude
Desktop (обычный чат). В Claude Code ставится весь плагин сразу. В claude.ai каждый скилл
загружается отдельным архивом.

## Claude Code

### Через маркетплейс (рекомендуется)

1. Откройте Claude Code и введите в чат:

   ```
   /plugin marketplace add Pav-377/youtube-agent-skill-ru
   ```

2. Затем:

   ```
   /plugin install youtube-agent-ru@youtube-agent-skill-ru
   ```

   Откроется окно плагина — нажмите «Install».

3. Перезапустите Claude Code или введите `/reload-plugins`.

То же самое можно сделать в терминале, не открывая чат:

```bash
claude plugin marketplace add Pav-377/youtube-agent-skill-ru
```

```bash
claude plugin install youtube-agent-ru@youtube-agent-skill-ru
```

**Как вызывать.** Пишите запрос обычными словами — нужный скилл включится сам. Если хотите вызвать
явно, наберите `/yt-script`. Если такое имя уже занято другим плагином, работает полная форма:
`/youtube-agent-ru:yt-script`. Так же для остальных команд.

### Вручную, копированием папок

Подходит, если не хотите ставить плагин. Скачайте архив `youtube-agent-skill-ru.zip` из последнего
релиза на GitHub, распакуйте и скопируйте папки `skills/yt-*` в папку `.claude/skills` в вашей
домашней папке (на Windows это `C:\Users\ВашеИмя\.claude\skills`). Команды тогда вызываются коротко:
`/yt-script`, `/yt-edit` и так далее.

## claude.ai и Claude Desktop

1. Включите выполнение кода: без него скрипты не запустятся, и останутся только текстовые
   инструкции. Где это включается — в [справке Claude](https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude).
2. Скачайте нужные архивы из последнего релиза на GitHub: `yt-script.zip`, `yt-edit.zip` и так
   далее. Каждый скилл — отдельный архив, ставьте только нужные.
3. Откройте **Customize → Skills**, нажмите **«+»**, затем **«+ Create skill»** и **«Upload a skill»**.
   Выберите архив. Повторите для каждого скилла.

Скиллы доступны на тарифах Free, Pro, Max, Team и Enterprise (по [справке Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)).
Скиллы, включённые в claude.ai, подгружаются и в Claude Code, если войти тем же аккаунтом.

**Профиль автора в claude.ai.** Папки `~/.claude` там нет. Попросите Claude составить профиль по
трём вашим роликам и вставьте готовый текст в инструкции проекта Claude — тогда все скиллы будут
его видеть.

## Как понять, что всё работает

Пройдите три коротких проверки.

1. Напишите: «Оцени начало ролика: Почему твои видео никто не досматривает?»
   **Должно получиться:** таблица с пятью строками (КОНКРЕТИКА, ОБРАЩЕНИЕ, СТАВКИ, ЛЮБОПЫТСТВО,
   КРАТКОСТЬ), итог и строка «слабое место». Если ответ на английском — скрипт не запустился
   или скилл не тот: проверьте, что включено выполнение кода.
2. Напишите: «Проверь название: ШОК! Вы не поверите, что сделал Claude».
   **Должно получиться:** предупреждение «кликбейт» про «шок» и «вы не поверите».
3. Напишите: «Найди штампы: Давайте разберёмся, почему это не просто монтаж, а искусство».
   **Должно получиться:** две находки — «канцелярская связка» и «противопоставление».

Если все три сработали, плагин установлен правильно.

## Если что-то не так

- **«python3 не найден» (Windows).** Скилл сам попробует команду `python`. Если нет и её —
  установите Python 3.9 или новее с [python.org](https://www.python.org/downloads/) и отметьте
  «Add Python to PATH».
- **Ответ на английском, хотя вы пишете по-русски.** Добавьте в запрос «ответь по-русски» или
  проверьте профиль автора.
- **Архив не загружается в claude.ai.** Загружайте архивы скиллов (`yt-script.zip` и другие), а не
  общий архив плагина.
