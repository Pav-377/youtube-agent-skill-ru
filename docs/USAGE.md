# Один ролик от идеи до публикации

Ниже весь путь на примере ролика «Как я монтирую видео на телефоне». Для каждого шага указано, что
написать Claude и что вы получите. Команду можно не набирать: Claude выберет её по тексту запроса.

## 1. Профиль автора

Сделайте это один раз. Напишите: «Вот ссылки на три моих ролика. Составь мой профиль автора».

Claude спросит, на «ты» или на «вы» вы обращаетесь к зрителю. Затем составит профиль по
[шаблону](../templates/voice.ru.md). Где хранится профиль, описано в
[инструкции по установке](INSTALL.md#профиль-автора).

## 2. Идеи: `/yt-viral`

«Что сейчас набирает просмотры у каналов про монтаж?»

Вы получите ролики, которые набрали в несколько раз больше просмотров, чем обычно на своём канале.
Для каждого указана формула названия. Если списка роликов нет, Claude предложит собрать открытые
данные через yt-dlp и спросит разрешения.

## 3. Сценарий: `/yt-script`

«Напиши сценарий про то, как я монтирую на телефоне. Минут восемь».

Claude напишет пять вариантов хука, оценит их и покажет два лучших с формулой и объяснением. Затем
напишет сценарий по частям с пометками «НА ЭКРАНЕ». Перед показом текст проходит проверку на
штампы, и найденные места Claude переписывает.

## 4. Название и обложка: `/yt-package`

«Придумай название и текст на обложку».

Вы получите десять названий, три лучших с оценкой и замечаниями, текст обложки и описание картинки
для обложки. Скрипт проверяет длину названия, повторы слов между названием и обложкой и кликбейт.

## 5. Монтаж: `/yt-edit`

«Вот автосубтитры записи. Что вырезать?»

Нужен транскрипт с таймкодами. Подходят три источника:

1. Автосубтитры YouTube в формате `.vtt`. Время каждого слова точное. Загрузите черновик как
   скрытое видео и скачайте субтитры:

   ```bash
   yt-dlp --write-auto-subs --sub-langs ru --skip-download ССЫЛКА
   ```

2. Whisper с пословным временем. Время тоже точное:

   ```bash
   whisper запись.mp4 --language ru --word_timestamps True
   ```

3. Обычный файл `.srt`. Время слов примерное и помечено знаком ≈.

Пример отчёта по автосубтитрам:

```
  transcript_ru.vtt   24,34 с, реплик: 10, слов: 67, порог паузы 0,45 с
  время слов точное

    ПАРАЗИТ      0,00 ->     0,32   0,32 с   KEEP  связка в начале фразы, живая речь   «Ну,»
    ЗАМИНКА      3,20 ->     3,52   0,32 с   CUT   звук-заминка   «Э-э...»
    ПАРАЗИТ      3,52 ->     3,84   0,32 с   CUT   несколько паразитов подряд   «короче,»
    ПАРАЗИТ      3,84 ->     4,16   0,32 с   CUT   несколько паразитов подряд   «типа,»
    ПОВТОР       7,04 ->     7,36   0,32 с   CUT   слово «я» сказано дважды
    ПАУЗА        9,19 ->    10,34   1,15 с   CUT   пауза 1,60 с
    ЗАМИНКА     10,56 ->    10,88   0,32 с   CUT   звук-заминка   «Мм,»
    ПАРАЗИТ     14,40 ->    15,04   0,64 с   KEEP  связка в начале фразы, живая речь   «В общем,»
    ПАРАЗИТ     16,32 ->    16,94   0,62 с   CUT   паразит внутри фразы, смысл не меняется   «как бы,»
    ПАУЗА       19,11 ->    19,55   0,45 с   CUT   пауза 0,90 с
    ПОВТОР      19,78 ->    21,38   1,60 с   CUT   фраза начата заново, первая попытка лишняя

  вырезать: 9, это 5,42 с; останется 18,92 с (короче на 22,3%)
  оставить как живую речь: 2
```

CUT означает «вырезать», KEEP означает «оставить».

## 6. Шортсы: `/yt-shorts`

«Нарежь шортсы из этого ролика».

Вы получите пять моментов с таймкодами. Для каждого момента Claude напишет новую первую фразу и
текст на экран. Последняя фраза шортса подводит к первой, чтобы ролик смотрели по кругу.

## 7. Главы и описание: `/yt-chapters`, `/yt-seo`

«Сделай таймкоды». Вы получите главы по правилам YouTube. Первая глава начинается с 0:00, глав не
меньше трёх, каждая длится от 10 секунд. Перед публикацией переименуйте главы своими словами.

«Напиши описание и теги». Вы получите первые строки описания, три поисковых запроса и несколько
тегов.

## 8. После публикации: `/yt-retention`, `/yt-comment`

«Разбери удержание». Приложите выгрузку из YouTube Studio: файл CSV или архив целиком. Пример отчёта:

```
  retention_ru.csv   точек: 12   100,0% -> 45,0%

  Позиции даны в % длины ролика. Чтобы получить секунды, добавьте --duration (длина ролика в секундах) или --transcript

  ХУК         в начале ушли 19,5% зрителей   [норма]
              Норма — меньше 25%. Сначала исправьте первую фразу, потом всё остальное.

  ОБРЫВЫ      моменты, в которые зрители уходили
    -  6,5%  на     40-50%
    -  6,5%  на     10-20%
    -  4,0%  на    90-100%
    -  4,0%  на     20-30%
    -  3,5%  на     70-80%

  СПАД        0,362% за 1% длины ролика в середине ролика
              Ровный спад говорит о темпе. Сократите середину, переписывать её не нужно.
```

Если приложить и транскрипт, Claude назовёт, что вы говорили в момент каждого обрыва.

«Ответь на комментарии». Вы получите комментарии, разделённые на четыре группы, ответы в стиле
вашего профиля и совет, какой комментарий закрепить. Публикуете ответы вы.

## 9. Следующая неделя: `/yt-plan`, `/yt-audit`

«Составь план на неделю, у меня 8 часов». Вы получите таблицу по дням и список того, что убрать
первым, если времени не хватит.

«Разбери мой канал». Вы получите одно главное исправление, три вещи, которые уже работают, и то,
что пока делать не нужно. Такой разбор полезно делать раз в месяц.
