# yt-chapters: русские примеры

Образцы формата для русского режима. Цифры, названия и ситуации в них придуманы для примера: это не факты и не реальные каналы, не цитируйте их как результаты.

## Как просят

- «Сделай таймкоды для этого ролика.»
- «Раздели видео на главы по транскрипту.»

## Как выглядит хороший ответ

```
0:00 Зачем снимать на телефон
1:42 Свет из окна вместо софтбокса
4:15 Звук: петличка за копейки
7:30 Монтаж за десять минут
```

Черновик скрипта давал «Камеру сначала поговорим» — названия переписаны в обещание раздела.
Проверено по правилам YouTube: первая метка 0:00, глав не меньше трёх, каждая длиннее 10 секунд.

## Чего избегать

- Вставлять черновые названия как есть: это слова темы, а не ваши слова.
- Главы короче 10 секунд — YouTube их не покажет.
