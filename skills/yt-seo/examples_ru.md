# yt-seo: русские примеры

Образцы формата для русского режима. Цифры, названия и ситуации придуманы. Не выдавайте их за факты.

## Как просят

- «Напиши описание и теги для ролика про монтаж на телефоне.»
- «Сделай так, чтобы видео находили в поиске.»

## Как выглядит хороший ответ

**Первые строки описания:** «Как смонтировать ролик на телефоне за 10 минут: весь процесс по шагам,
бесплатное приложение и три приёма, которые экономят час.»

**Три запроса, которые ролик должен выигрывать:** «монтаж на телефоне», «как монтировать видео
на телефоне», «бесплатный монтаж видео». Слова из них есть и в названии, и в первых строках.

**Теги (немного):** монтаж на телефоне, монтаж видео, CapCut, капкут.

По справке YouTube, теги почти не влияют на поиск. Они нужны для написаний и транслитераций,
которые набирают зрители.

## Чего избегать

- Стену из пятидесяти тегов: это нарушает правила YouTube о спаме.
- Писать описание словами, которых зритель не набирает.
