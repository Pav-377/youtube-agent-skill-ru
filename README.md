# YouTube-агент для Claude

Плагин для Claude с 11 командами для автора YouTube: сценарий, название и обложка, монтаж,
удержание, шортсы и другие задачи. Работает на русском и английском языках.

## Команды

| Команда | Что делает | Пример запроса |
| --- | --- | --- |
| `/yt-script` | Пишет сценарий: пять вариантов хука (первых секунд ролика) с оценкой, затем текст по частям | «Напиши сценарий ролика про монтаж на телефоне» |
| `/yt-package` | Пишет название и текст обложки, проверяет длину, повторы и кликбейт | «Придумай название и текст на обложку» |
| `/yt-edit` | Составляет монтажный лист по транскрипту: паузы, заминки, слова-паразиты, повторы | «Вот субтитры записи. Что вырезать?» |
| `/yt-retention` | Разбирает выгрузку удержания из YouTube Studio: где уходят зрители и почему | «Разбери удержание» |
| `/yt-shorts` | Находит в длинном ролике моменты для шортсов и пишет к ним первые фразы | «Нарежь шортсы из этого ролика» |
| `/yt-chapters` | Делает главы по транскрипту по правилам YouTube | «Сделай таймкоды» |
| `/yt-seo` | Пишет описание и теги под поисковые запросы | «Напиши описание и теги» |
| `/yt-comment` | Сортирует комментарии и пишет ответы в стиле автора | «Ответь на комментарии» |
| `/yt-plan` | Составляет план публикаций под ваше время | «Контент-план на неделю, у меня 8 часов» |
| `/yt-audit` | Проверяет канал и называет главное исправление | «Разбери мой канал» |
| `/yt-viral` | Находит ролики в нише, которые набрали больше обычного для своего канала | «Что сейчас набирает просмотры в теме монтажа» |

Каждая команда устроена как отдельный скилл Claude. Команду можно не набирать: Claude выберет её
по тексту запроса.

## Требования

- Claude Code или claude.ai с включённым выполнением кода.
- Python 3.9 или новее. Сторонние библиотеки не нужны. Как установить Python, описано в
  [инструкции по установке](docs/INSTALL.md#если-нет-python).

## Установка

### Claude Code: через сообщение

1. Откройте Claude Code.
2. Отправьте сообщение: «Установи этот плагин: {{REPO_URL}}»
3. Когда Claude сообщит, что плагин установлен, откройте новый чат.

### Claude Code: командами

Введите в чате Claude Code две команды по очереди:

```
/plugin marketplace add {{OWNER}}/{{REPO}}
```

```
/plugin install youtube-agent-ru@youtube-agent-skill-ru
```

Затем откройте новый чат.

### claude.ai

1. Включите выполнение кода в настройках claude.ai.
2. Скачайте архивы нужных скиллов со страницы релизов: {{REPO_URL}}/releases
3. Откройте Customize → Skills, нажмите «+», затем «Create skill» и «Upload a skill». Выберите архив.

Подробности и проверка установки: [docs/INSTALL.md](docs/INSTALL.md).

## Быстрый старт

1. Составьте профиль автора. Напишите «Составь мой профиль автора по трём роликам» и приложите
   ссылки или транскрипты. Команды, которые пишут текст, используют этот профиль.
2. Попросите сценарий: «Напиши сценарий ролика про монтаж на телефоне».
3. Проверьте хук отдельно: «Оцени начало ролика: Почему твои видео никто не досматривает?»

Claude запустит оценку и покажет такой отчёт:

```

    ИТОГ           43
    формула       Вопрос  (совпало шаблонов: 2)
    слабое место  ставки: назовите, что зритель теряет, если продолжит делать как сейчас
```

## Ограничения

- Плагин не публикует ролики, не монтирует видеофайлы и не входит в аккаунт YouTube.
- Оценка хука отсеивает слабые начала и подсказывает, что исправить. Просмотры она не предсказывает.
- Названия столбцов русской YouTube Studio не сверены с реальной выгрузкой.
- Поддерживается только YouTube.

Полный список: [docs/LIMITATIONS.md](docs/LIMITATIONS.md).
